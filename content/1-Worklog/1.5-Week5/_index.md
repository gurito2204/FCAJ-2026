### Week 5 Objectives:

- Learn and practice using advanced AWS services: EC2 Auto Scaling, Amazon CloudWatch, Amazon Route 53, and AWS CLI.
- Master monitoring, auto-scaling resources, and configuring domain routing on the AWS infrastructure.

### Tasks to be carried out this week:

| Day | Task                                                                                                                                                        | Start Date | Completion Date | Reference Material                        |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- | --------------- | ----------------------------------------- |

| 3   | - Learn about the monitoring service **Amazon CloudWatch** <br> - Practice creating Metrics, Alarms, and Dashboards to monitor system resources             | 12/07/2026 | 18/07/2026      | <https://cloudjourney.awsstudygroup.com/> |

| 5   | - Master and practice operating with **AWS CLI** <br> - Manage, query, and control AWS services via the command-line interface                              | 12/07/2026 | 20/07/2026      | <https://cloudjourney.awsstudygroup.com/> |

### Week 5 Achievements:

- Understood the operational mechanics of **EC2 Auto Scaling**, automatically adjusting the number of server instances based on actual traffic demand.
- Successfully configured **Amazon CloudWatch** to monitor system performance (CPU, Memory, Network) and set up automated alerts for issues.
- Mastered **Amazon Route 53**, learning how to manage domain names and route traffic to AWS resources effectively.
- Gained proficiency in using **AWS CLI** to automate administrative tasks and quickly query system information.
